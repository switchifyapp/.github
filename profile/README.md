# Switchify

**Operate any Android phone or tablet with adaptive switches.**

Cursor scanning, item scanning, camera-based head control, customisable scan speeds, and external switch support. Built for users with mobility impairments who can't use a touchscreen.

[**Get it on Google Play**](https://play.google.com/store/apps/details?id=com.enaboapps.switchify) · [**switchifyapp.com**](https://switchifyapp.com)
